- 前端 `vlScriptActions` 未定义、旧脚本缓存问题已修。

### 4.2 仍未最终确认/可能有问题

1. **AI 预热完不自动继续播放**
   - 旧实现：AI 启动时 `v0.pause()`，再靠程序化 `play()` 恢复，WebView2 拒绝无手势播放；且 `_autoplayed` 一次失败后锁死。
   - 本轮末改为：**AI 启动不再暂停视频**；若本来暂停则用按钮手势立即 `play()`；预热完成仍保留静音重试。
   - 已热更新到安装目录（`app.js?v=20261019c`）并清了 WebView2 Cache，但用户尚未确认。
2. **设备动作**
   - 已修：AI 启动后 `SYNC.on=true`（20ms tick 才会跑）；设备连接时若识别在跑则 `start_live`。
   - **尚未用真机验证**；若仍无动作，先查 `/api/state` 的 `device.connected`、`vision.engine_state`、`/api/sync/tick`。
3. **安装包与安装目录可能不同步**
   - 最后一次 `Setup-1.0.93.exe` 构建早于 `app.js?v=c` 的热修；**安装包里的 UI 可能还是旧版**。
   - 安装目录 `D:\...` 已手工替换 `ui-legacy/app.js`、`index.html`。
   - 发布前必须重新执行 `build_installer.ps1`，并确认安装包内 `index.html` 是 `app.js?v=20261019c`。
4. **CPU 占用**
   - 实测识别进程约 3.9 核、GPU 26%（K1drsp 全片处理中）；不是泄漏。
   - 主要 CPU 来自“整片转码 480p30 + 流式编码”；22 分钟片转码阶段会持续数分钟、吃多核。
   - `ffmpeg` 空闲时接近 0 核；若长期满载，先看 `vendor/vision/cache/*.mp4` 是否在重复转码。
5. **`host.log` 看不到识别服务启动行**
   - 观察到的现象：14:42 会话识别在跑，但 host.log 没有 `识别服务解释器` 行；原因未查。
   - 排查方向：`RT.add_log` 的日志路径/级别、是否写到了旧 `logs/`、服务是否被复用。
6. **旧 `vision-runtime` 仍存在**
   - 安装目录下仍有旧 Python 运行时（已把 onnxruntime 换成 DML）；产品新装不应再依赖它。
   - Rust 线完成后应彻底移除；现阶段保留可回退。

## 5. 本轮关键决策与修复

### 5.1 去 torch / ONNX 默认

- 默认后端：`config.json engine.backend = "onnx"`；环境变量 `FSC_VISION_BACKEND` 可覆盖。
- Python 3.10 的 DML 轮子固定 `onnxruntime-directml==1.23.0`（1.24.4 无 cp310）。
- `build/make_runtime.ps1` 已改为：安装 fastapi/faster-whisper 后，**删除 CPU onnxruntime，安装 directml 1.23.0**。
- 宿主 `_vision_probe_script` 对 onnx 后端要求 `DmlExecutionProvider` 或 `CUDAExecutionProvider`，避免误选 CPU-only 解释器。

### 5.2 静止门（最新落地版）

- 代码：`vendor/vision/still_gate.py`（从 `tools/vision` 迁入）。
- 接入：`vendor/vision/onnx_stream.py` 的 `_style()`，出点后、发布前过滤。
- 默认 `combo`：`conf>=0.70`、`|vmarg|>=50 pos/s`、`score>=0.70`，窗口 ±0.2s。
- 开关：`config.json engine.still_gate` / `FSC_VISION_STILL_GATE=off|and|or|combo`。
- 实测：K1cztm 400–430s，未门控 70 → combo 46。
- **已知限制（文档 §6 原文）**：动作级“删点”，静止段会停在最后一个保留动作的位置；若要“停在正确位置”，需方案 A（样式合成前把 still run 速度置零）——**当前未实现**。
- 文档：`vendor/vision/STILLNESS_ANALYSIS.md`、`HOW_IT_WORKS.md`。

### 5.3 宿主/前端链路

- `vision_state()` 复用外部服务时也探测 `/health`，修复 UI 永远 idle。
- `/api/vision/open`：设备已连接才 `start_live`；`/api/device/connect`：连接成功后若识别在跑，补 `start_live`。
- `ui-legacy/app.js`：
  - `vlScriptActions` → `heatActions()`；
  - AI 启动成功置 `SYNC.on / SYNC.ai`，20ms tick 才会调用 `/api/sync/tick`；
  - AI 启动**不暂停视频**；预热完成对暂停视频持续静音重试；
  - 脚本版本 `app.js?v=20261019c`（安装目录已换，安装包待重建）。

### 5.4 目录/数据迁移

- 运行期数据统一到 `var/{data,logs,run,backup}`；`vendor/subtitle/user_paths.py` 有旧目录迁移逻辑。
- 安装目录同时存在旧 `data/` 与 `var/data/`；旧目录未删，确认无误后再清理。
