## 开发纪律速查（新会话先读）

1. **行为真源 = 手机端**（`E:\Development\FunScriptCast`）。不许臆测；先查原机制再写新代码。
2. **实测优先**：改 UI 必须浏览器/真机验证（截图）；热替换 `ui/` 后**必须重启应用**（WebView2 不自动重载）。
3. **迭代归档**：每轮写 `iteration_shturl.md`；教训必须写进项目文档与记忆。
4. 提交：`prepare-commit-msg` 钩子固定提交信息；`ui/app.js` 等 CRLF 文件用
   `git -c core.autocrlf=false add`。
5. 部署 = 仓库 → `tools/sync_distapp.ps1` → 复制 `dist-app\vendor` 到 D 盘 → 重启宿主
   （只 sync 不等于部署）。D 盘运行版 = 用户实际使用环境。
6. **安装/升级（全自动，无需点击）**：先退出宿主，然后
   `FunScriptCast-Nexus-Setup-<版本>.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /LOG=<日志>`
   （setup.iss 自 R118.2 起带 WizardSilent 守卫，升级/重装/降级都不弹窗）；
   装完跑 `D:\FunScriptCast-Nexus\runtime\python.exe tools\verify_install.py` 一键验证。
7. **发布/推送属用户决策域**（当前"测试中，不推送"）。构建：`build\build_installer.ps1`。
8. 评测先审计口径（`tests/score_combo.py` 文件头），再谈数字。
