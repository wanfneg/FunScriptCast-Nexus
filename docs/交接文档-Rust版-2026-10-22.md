## 2. 本版（1.1.14）改动

### 2.1 Vulkan 适配

- **ASR**：`vendor/audiocpp/vulkan`（audio.cpp v0.7.4 Vulkan）。
  - 实测启动参数为 `audiocpp_server.exe --backend vulkan`，`/health` 返回 `"backend":"vulkan"`。
- **翻译**：`vendor/llama-vulkan`（llama.cpp b11000 Vulkan）。
  - `llama-server.exe --list-devices` 能列出 Vulkan GPU。
- **后端选择规则**（`rust/crates/nexus-host/src/subtitle_service.rs`）：
  - 配置 `cuda` + CUDA 运行时存在 + NVIDIA → `cuda`
  - 否则有 Vulkan 运行时且 Vulkan 能看到 GPU（NVIDIA/AMD/Intel）→ `vulkan`
  - 否则 `cpu`
- 旧配置里的 `asr.backend=whisper/lccapture` 自动迁移为 `audiocpp`；`asr.model=lccapture` 迁移为 Qwen3-ASR-0.6B。

### 2.2 CUDA 改为可选下载

- 安装包**不再包含** CUDA（约 3GB）：移除了 `vendor/llama`、`vendor/audiocpp/gpu`。
- 安装包内含 CPU + Vulkan 运行时；CUDA 在「AI 字幕 → 模型下载」中作为两个可选条目：
  - `翻译 CUDA 加速包（可选下载 · NVIDIA）` → `vendor/llama-cuda`
  - `识别运行时 · CUDA` → `vendor/audiocpp/gpu`
- 下载器支持多 zip、断点续传、系统代理 / `NEXUS_PROXY`。
- **安装 1.1.14 会删除旧版随包的 CUDA 目录**；需要 CUDA 时重新下载。

### 2.3 UI / 交互

- 仪表盘：删除“刷新”“一键启动”；系统资源与服务状态卡对调。
- 应用图标：exe 资源、窗口、托盘、标题栏品牌图标、安装包 SetupIcon 统一使用 `tools/icon.ico|png`。
- 窗口比例：视频播放区固定 16:9；窗口按默认布局反推为 **1280×1056（≈1.212:1）**，拖动缩放锁定；全屏/最大化交给系统。
- 播放器：
  - “更多”改为控件内浮层菜单，按钮显示 `···`。
  - AI 识别旁新增“选择脚本”，原生文件框过滤 `.funscript`，后端 `POST /api/library/script` 可加载任意脚本。
  - 修复热力曲线/mini 热力条的数据形状不匹配（脚本接口是 `[at,pos]` 数组，旧构建器只认对象）。
- 媒体库：
  - 修复 169 张卡时 `grid-auto-rows:auto` 把行高压成 4.58px 导致叠卡；现在按列宽和卡片比例计算行高。
  - 缩略图固定宽高比；设置页「媒体库 → 卡片比例」可选 16:9 / 4:3；行数随窗口自动增加。
- 全屏：新增 `native_fullscreen` 标志，全屏 Resize 不再被窗口比例修正；CSS 让视频区铺满视口。
- DLNA：日志固定为页面底部卡片，删除“展开日志”，日志框内部滚动。
- 版本显示去掉 `-rust` 后缀（应用内、窗口、安装包显示名）。

## 5. 构建与出包

```powershell
# 1) 版本号 +1
powershell -ExecutionPolicy Bypass -File tools\bump_version.ps1

# 2) 补齐 Vulkan 运行时（仓库不入 git 的大文件）
powershell -ExecutionPolicy Bypass -File tools\fetch_llama_vulkan.ps1 -Proxy http://127.0.0.1:7897

```

产物：`artifacts\installer-rust\FunScriptCast-Nexus-Rust-Setup-<版本>.exe`

## 8. 常见排障

| 现象 | 排查 |
|---|---|
| 字幕页设备显示 cpu | 看 `vendor/audiocpp/vulkan` 是否存在、`audiocpp_server --backend vulkan --list-devices` 是否列出 GPU |
| 显示 cuda 但不动 | 确认 NVIDIA + `vendor/audiocpp/gpu`，看 `/health` 的 backend |
| 翻译起不来 | 确认 `vendor/llama-vulkan` 或 `vendor/llama-cuda` 有 `llama-server.exe`；看 8082 端口 |
| 模型下载失败 | 看 `var/logs/host.log`；GitHub 下载设 `NEXUS_PROXY`；模型直链可用浏览器验证 |
| 全屏不是真全屏 | 确认安装的是 1.1.14+；看宿主是否收到 `win_fullscreen` |
| 媒体库卡片叠在一起 | 确认 `app.js` 含 `layoutLibGrid` 且版本号已更新 |
