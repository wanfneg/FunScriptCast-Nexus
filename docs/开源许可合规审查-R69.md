# 开源许可合规审查报告（R69）

> 技术合规评估，不构成法律意见。审查对象：E:\Development\FunScriptCast-Nexus（含 dist-app 安装包组装物、D 盘自包含安装实例、运行时下载清单）。

## 审查概要
- 项目路径：E:\Development\FunScriptCast-Nexus
- 审查范围：git 跟踪 127 个文件 + 发行 runtime 的全部 Python 发行包（约 40 个）+ 随包分发的二进制（adb、llama.cpp DLL、字体×3）+ 运行时下载清单（模型权重、llama-runtime）
- 发现风险项数量：2 项需整改 + 4 项声明文件补齐
- 最高风险等级：🔴（GPLv2+ 组件进入闭源安装包——zhconv）

## 一句话结论
装进安装包的 Python 运行时里躺着两个"死乘客"：**zhconv（GPLv2+，代码里有可选引用）** 和 **PyAV（捆绑 FFmpeg LGPL DLL，代码零引用）**——两者卸载即根治，功能零损失；其余全部是"补一份许可证文本"的轻活。没有发现 GPL 代码被复制进自有源码。
