# FunScriptCast-Nexus 发布说明

## 1.0.42

### 新增：识别 GPU 加速（CUDA 运行时，实测约 16 倍）

- 「识别与翻译」卡的模型列表新增**「识别运行时 · GPU 加速」**：一键下载 audio.cpp CUDA 版
  （约 1.1GB，断点续传），下载完成**自动切换为 GPU 识别**并重启字幕服务
- 同段 10 秒日语实测：CPU 8.0 秒 → **GPU 0.49 秒**（RTF 0.80 → 0.049，约 16 倍），字幕出字更快
- 「识别引擎」下拉改为 **CPU / GPU** 二选一：GPU 项只在运行时下载后出现；随时切回 CPU，立即生效
- 可靠性：GPU 运行时缺失（未下载/被删）时自动回退 CPU 识别，字幕链路不会瘫痪
- 显存提示：GPU 识别 + 本地翻译同卡约 7.5GB（8GB 卡实测余量约 500MB）；空闲自动回收显存

## 1.0.17

### 新增：AI 字幕模型一键下载（新机器开箱即用）

- 全新安装不再需要手动找模型：AI 字幕页「识别与翻译」卡底部列出识别 / 翻译模型，缺什么点什么

### 新增：识别引擎双选一（界面可切换）

- **Whisper**（日文特化，现为出厂默认）：整片实测内容覆盖 **+12%**、时序中位 −90ms→**+30ms**、识别快约 3 倍

- 状态页实时显示实际生效的引擎与识别模型

### 新增：自带 adb

- 设备同步不再要求电脑装过 Android 工具：应用自带 adb（可用界面路径覆盖）

### 改进：界面减负

- 仪表盘 SIGNAL 波形动画替换为 **CPU / GPU / 内存 / 显存** 四个占比圆环，空闲时零动画开销
- 输入框不再显示灰色示例内容；清理全部开发向说明文字
- 识别调优参数（分段 / VAD 等）收进配置文件，不再暴露给用户
- 术语表新增总开关（关闭后不注入热词/术语，词表保留，即时生效）

### 修复

- 特定场景命令行黑窗闪烁（识别时每 3 秒闪一次 VAD 窗、启停服务闪 netstat/taskkill 窗）
- Windows 11 窗口边缘的系统色描边去除
- 稳定性：模型缺失不再导致服务崩溃；翻译单句失败不再报废整块字幕；若干竞态与边界修复

## 1.0.3

### 本版修复：AI 字幕 25 秒卡顿（实测 8K 日语片源）

**症状**：某些片段 ASR 固定耗时约 25 秒，字幕严重落后画面。

**根因**：Qwen3-ASR 默认 `max_new_tokens=512`。非语音/音乐段模型会退化生成
（一直吐 token）直到打满上限，0.6B 模型约 20 tok/s → 每块固定 ~25 秒。
实测与音频长度无关：5s / 10s / 25s 的块都是 25 秒。

**修复**

| 措施 | 说明 |
|---|---|
| 动态生成上限 | 按音频时长收紧（4 token/秒，夹在 48~256），可配置 |
| VAD 裁剪 | 不再只判断「有无语音」，而是切出语音区间，只把语音段送 ASR（含 0.25s padding），时间戳映射回原时间轴 |
| 重复退化过滤 | 阈值 5 → 3（「ああああ気持ちああ」这类喘息会污染翻译） |
| 译文异常放大过滤 | 译文长度 > 原文×3 且单字占比 >60% → 丢弃，避免「啊啊啊啊…」刷屏 |

**实测（FCVR-40-3.mp4 · 日语 · 3 分钟，RTX 4070 Laptop）**

| 指标 | 修复前 | 修复后 |
|---|---|---|
| 最差块 ASR | 25 600 ms | **1 782 ms** |
| 非语音块 ASR | 25 600 ms | **633 ms** |
| 翻译 | 46~4 976 ms | 80~183 ms |
| 退化译文 | 「啊啊啊…」（31 字） | 已过滤 |

### 本版内容

**设备同步（新增页）**
- 脚本 / 视频 → Quest 的 adb 增量推送，真机验证：本地 1 / 设备 2707 / 本次推送 1
- 自动探测 adb，支持 USB 与无线连接，日志实时回传

**术语表 CSV 导入 / 导出**
- 导出 UTF-8 BOM（Excel 直开不乱码）

**窗口与托盘**
- 无边框自绘标题栏（可拖动），用 `WS_THICKFRAME` 找回原生缩放边框 + DWM 圆角

- PyInstaller 单文件 EXE；torch（4 GB）与模型（8 GB）不进包，字幕服务仍走 `.venv` 子进程

- 字幕服务改用管道接输出，秒退时把最后几行作为错误上报，不再假死

- 字幕服务另需 NVIDIA GPU（CUDA）+ `.venv` + `models`
