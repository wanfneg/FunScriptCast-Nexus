四步出字幕

装好后跟着走一遍，之后就是「打开播放器看片」这么简单
安装

下载 FunScriptCast-Nexus-Setup，向导里选安装目录。选空间充足的盘（模型以十 GB 计），C 盘一个字节都不落。

添加媒体库

「DLNA 服务器」页添加电脑上的视频目录，服务自动启动；头显 / DeoVR 在同一局域网会自动发现设备 FunScriptCast-DLNA。

下载模型

「AI 字幕」页模型列表点下载：至少一个识别模型（0.6B 够用 / 1.7B 更强），再选一个翻译模型（日语 Sakura / 英语 Hy-MT2，各有低显存与高画质两档）。支持断点续传。

开字幕

点「启动服务」，状态变「就绪」即可。播放器正常播放，中文字幕自动上屏；空闲 5 分钟（可调）自动回收显存，下次播放自动再起。

仪表盘：服务状态一目了然

DLNA / 字幕服务 / GPU 遥测 / 事件流，全部实时

DLNA 媒体服务

面向 DeoVR 的轻量媒体服务
  • 头显 / 播放器自动发现，中文文件名不乱码
  • 视频同目录的外挂字幕（.srt / .ass / .vtt）播放时直接切换
  • 媒体根目录随意加几个盘，路径带引号空格自动规整

AI 实时字幕

本地识别 + 本地翻译，片库全程不过云端
  • 识别：Qwen3-ASR 本地常驻推理，日语 / 英语（CPU 运行时已内置安装包，N 卡可切 CUDA 提速）
  • 混合切句：静音定界 + 语音检测赋时，整句出字、时间戳准；长句渐进出字，临时稿先上屏
  • 翻译按片源语言自动路由：日语走 Sakura 系、英语走 Hy-MT2 系，热切换不重启
  • 翻译预热：启动即付完冷启动的账，首句字幕不卡
  • 「测试一句」真翻一句给你看：直连译文 / 管线译文 / 上游报错三段分明

常见问题

显存不够 / 提示降档？

翻译换低显存档（Sakura-1.5B / Hy-MT2-1.8B），或把识别换回 0.6B。

首句字幕特别慢？

多为服务刚启动的一次性成本（模型加载 + 预热），之后正常。

播放没有字幕？

仪表盘看「AI 字幕服务」是否就绪；模型未安装会在下载列表标出。

下载中断了？

直接重试，断点续传接着下。

想彻底重来？

关程序后删安装目录里的 data\，即恢复出厂（模型不受影响）。
