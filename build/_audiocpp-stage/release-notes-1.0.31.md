# FunScriptCast-Nexus 1.0.31

1.0.20 以来识别/翻译引擎全面换代，全新安装链路重新打通。

## 全新安装
- **ASR 运行时已内置安装包**（audio.cpp CPU 版）：装完只差在界面里下载模型权重，不再需要手工安置任何运行时。
- 模型全部在界面「识别与翻译」卡一键下载（ModelScope / HF 镜像直连，系统代理兜底，断点续传），列表带显存标注。
- 本地翻译运行时（llama.cpp · CUDA，约 627MB）在下载列表内一键获取。

## AI 字幕
- 识别引擎换代：Qwen3-ASR 本地常驻（日语 / 英语）。
- 混合切句：静音定界 + 语音检测赋时，整句出字，时间戳更准。
- 渐进出字：句子还没切出时先发临时稿，定稿自动覆盖。
- 翻译按语言路由：日语走 Sakura、英语走 Hy-MT2-7B，自动切换、可自选档位（1.5B/1.8B 低显存 或 7B 高质量）。
- 翻译预热：首句字幕不再支付模型冷启动的账。
- Qwen3-ASR-1.7B 提供下载（官方分片权重自动合并为单文件）。

## 其他
- 设置/模型/日志全部落安装目录，不写 C 盘。
- 第三方组件许可声明齐备（见安装目录与仓库 docs/THIRD-PARTY-NOTICES.md）。
