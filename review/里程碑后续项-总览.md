## M3 · 遥控接收侧（未开始；规格已全部在手）

**真源**：
- 手机端 `HidRemoteController.kt`：变身蓝牙 HID 键盘，七键固定 ——
  **F13 急停 / F14 爆发 / F15 行程+ / F16 行程- / F17 速度+ / F18 速度- / F19 待机缓动**
  （按住由电脑端键盘重复率连发，手机不重复发送）。
- 手机端使用说明（Screens.kt:2200-2204）：电脑端要有「**启用遥控器功能**」开关、「**遥控模式设置**」
  （把快捷键绑定为对应按键）、「**调整幅度**」（行程/速度每次增减幅度由电脑端决定）；
  配对流程 = 电脑"添加蓝牙设备"→ 手机"让电脑搜索本机"。
- 原端 ServeU Central 热键：Ctrl+Alt+M / Ctrl+Alt+O / F19 / F13-F18（Central 开发方案 §9.4 要求兼容）。

**Nexus 侧要做的事（Python/WebView 版）**：
1. 设置页「遥控器」卡：启用开关（默认关）+ 七个动作的按键绑定（默认 F13–F19）+ 调整幅度两个数值。
2. 宿主**全局键盘拦截**（Windows `WH_KEYBOARD_LL` 低级钩子；**仅启用时挂钩**，关闭即卸载）。
3. 按键 → 动作映射：急停/爆发/缓动 → `/api/quick`；行程±/速度± → 改 `range_*` / `max_speed`。
4. 配对引导文案（照手机端使用说明）。

**待你定**：① 行程/速度每次增减的默认幅度（如行程 ±5%、速度 ±25 Units/s）；② 绑定是否允许自定义
（原端可自定义，手机说明也写"绑定为对应按键"）还是固定 F13-F19；③ 除七个动作外是否要更多
（原端还有 Ctrl+Alt+M/静音、Ctrl+Alt+O）。
