# uunScriptCast-Nexus UI 设计规范

> 把 **VR-DLNA** 与 **AI 字幕服务端** 合并为一个 PC 桌面软件。
> 技术栈：Python 主进程（DLNA + UI 宿主）+ pywebview(WebView2) 前端 + 字幕服务子进程。
> 本文件是设计基线，实现阶段以本文件的 token 与规则为准。

---

## 1. 设计定位

| 维度 | 定位 |
|---|---|
| 气质 | **沉浸式暗色**，面向"戴上头显前/后"的桌面控制台 |
| 关键词 | 深空、玻璃、微光、流体、克制 |
| 隐喻 | 主界面是一条"能量轨道"：服务状态沿轨道流动，启停有明确的能量感 |
| 目标 | 一眼看懂"现在在跑什么"，一次点击完成"启停/同步" |

**不做**：拟物、大面积渐变堆叠、无意义装饰动效、超过 300ms 的入场动画。

## 2. 设计 Token

### 2.1 色彩

```css
/* 背景层级（从深到浅） */
--bg-void:      #07090f;   /* 窗口底 */
--bg-base:      #0b0e16;   /* 内容区 */
--bg-raise:     #11151f;   /* 卡片 */
--bg-raise-2:   #171c28;   /* 卡片内嵌 / 输入框 */
--bg-hover:     #1d2432;

/* 描边与分割 */
--line:         rgba(255,255,255,0.06);
--line-strong:  rgba(255,255,255,0.12);

/* 文字 */
--ink:          #e8ecf4;   /* 主文本 */
--ink-2:        #9aa4b8;   /* 次要 */
--ink-3:        #5f6a80;   /* 弱化 / 占位 */

/* 品牌与语义色 */
--accent:       #4cc9f0;   /* 主强调（青） */
--accent-2:     #7b5cff;   /* 次强调（紫） */
--accent-glow:  rgba(76,201,240,0.35);
--ok:           #3ddc97;
--warn:         #ffb84d;
--danger:       #ff5c7c;
--info:         #5c9dff;

/* 语义色浅底（用于徽标/标签） */
--ok-soft:      rgba(61,220,151,0.14);
--warn-soft:    rgba(255,184,77,0.14);
--danger-soft:  rgba(255,92,124,0.14);
--accent-soft:  rgba(76,201,240,0.12);
```

**用法约束**
- 每屏强调色面积 **< 8%**，避免"发光污染"。
- 语义色只用于状态，不用于装饰。
- 暗色下禁止纯白 `#fff` 文字（用 `--ink`）。

### 2.2 字体

```css
--font: "Inter", "Segoe UI Variable", "Microsoft YaHei UI", system-ui, sans-serif;
--font-mono: "JetBrains Mono", "Cascadia Mono", Consolas, monospace;
```

| 层级 | 字号 / 行高 / 字重 | 用途 |
|---|---|---|
| Display | 28 / 34 / 600 | 仪表盘大数字 |
| H1 | 20 / 28 / 600 | 页面标题 |

| Caption | 11.5 / 16 / 500 | 辅助说明、单位 |
| Mono | 12 / 18 / 500 | 路径、IP、端口、日志 |

### 2.3 间距 / 圆角 / 阴影

```css
--r-sm: 6px;  --r-md: 10px;  --r-lg: 14px;  --r-xl: 20px;  --r-pill: 999px;
--sp-1: 4px; --sp-2: 8px; --sp-3: 12px; --sp-4: 16px; --sp-5: 24px; --sp-6: 32px;
--shadow-1: 0 1px 2px rgba(0,0,0,0.4);
--shadow-2: 0 8px 24px rgba(0,0,0,0.45);
--shadow-glow: 0 0 0 1px var(--accent-glow), 0 8px 28px rgba(76,201,240,0.18);
```

**栅格**：内容区最大宽度 1180px，左右内边距 28px；卡片间距 16px；卡片内边距 18px。

### 2.4 动效 Token

```css
--dur-fast: 120ms;   /* hover / 按下 */
--dur-base: 200ms;   /* 展开、切换 */
--dur-slow: 320ms;   /* 页面切换、抽屉 */
--ease-out: cubic-bezier(0.22, 1, 0.36, 1);      /* 进入 */
--ease-in-out: cubic-bezier(0.4, 0, 0.2, 1);     /* 位移 */
--ease-spring: cubic-bezier(0.34, 1.56, 0.64, 1);/* 弹一下（仅用于开关/徽标） */
```

## 4. 页面设计

### 4.1 仪表盘（首页）

**信息优先级**：当前在跑什么 > 谁连着 > 快捷动作。

- **状态轨道（Hero）**：一条横向能量轨道，节点为「DLNA 服务 → 字幕服务 → VR 设备」。每个节点：
  - 圆形指示灯（运行=呼吸动画，停止=静态灰）
  - 名称 + 一行副文本（如 `:8899 · 3 个媒体根`）
  - 节点间连线有"流光"沿方向跑（仅运行中显示，8s 循环，`transform` 位移，不触发重排）
- **指标卡 ×4**：媒体根目录数 / 已同步视频数 / 字幕块吞吐 / 显存占用。
  - 数字用 `requestAnimationurame` 做 0→目标值的计数动画（600ms，`ease-out`）。
  - 显存卡带环形进度（SVG `stroke-dashoffset`），超过 85% 变 `--warn`。
- **快捷动作区**：`启动/停止 DLNA`、`启动/停止字幕服务`、`同步视频到设备`、`打开媒体根`。
  - 主按钮带 `::after` 径向波纹（点击时 240ms 扩散）。
- **最近事件**：时间线列表，最多 5 条，新条目从上方滑入 8px + 淡入。

### 4.2 DLNA 服务器

- **服务卡**：开关（带 `--ease-spring` 滑块）+ 端口输入 + 本机地址（`192.168.2.2:8899`，一键复制）+ 运行时长。
- **媒体根列表**：每行 = 文件夹图标 + 路径（mono，中段省略）+ 视频数 + 删除按钮（hover 才显现，`opacity` 过渡）。
  - 拖拽排序（HTML5 DnD），拖拽时行 `scale(1.01)` + 阴影加深。
  - 空态：虚线框 + 说明 + "添加目录"按钮。
- **底部**：`浏览零探测` 等特性徽标（只读说明）。

### 4.3 同步（脚本 / 视频）

- 顶部 **分段控件**（Segmented）：`脚本文件夹同步` / `视频文件夹同步`，切换时下划线滑块滑动 200ms。
- 每段内容：
  - **源 → 目标** 可视化：左侧本地文件夹选择，中间箭头（同步时箭头有流动虚线），右侧设备目录。
  - 设备选择：ADB 设备下拉（含 `已连接/离线` 状态点）。
  - 选项：`全量同步`、`删除多余文件`（危险操作需二次确认，确认按钮为 `--danger`）。
  - **进度**：细进度条 + `已复制 128 / 350` + 当前文件名（mono，超长中段省略）。
  - 日志折叠区：默认折叠，展开高度 200px，等宽字体，自动滚底。

### 4.4 AI 字幕服务

- **服务状态卡**：子进程状态（未启动 / 加载中 / 就绪 / 错误）、模型名、设备（cuda:0）、显存占用环形图、启动/停止按钮。
  - 「加载中」时按钮内嵌**不确定进度条**（左右往复，1.2s）。
- **ASR 设置**：模型路径（只读展示 + 重新检测）、设备、dtype、VAD 开关与阈值。
- **翻译设置**：后端下拉（`ollama` / `dashscope` / 关闭）、模型、API Key（密码框，可切换明文）、连通性测试按钮（结果以徽标显示）。
- **术语表**：左右双列（日→中 / 英→中），可搜索、可增删改，行 hover 高亮；右上角显示条目数与"热重载"按钮。
- **分段/分块设置**：`max_sec`、`max_chars`、`pause_sec`、`min_sec`、`min_chars` —— 用滑块 + 数字联动（拖动时数字实时更新）。
- **实时预览**：最近 5 条转写结果（原文 + 译文），新条目滑入；空白时显示"等待头显推流…"骨架屏（微光扫过）。

### 4.5 设置

- 分组卡片：**启动**（开机自启、启动最小化、关闭到托盘、启动时自动开 DLNA）、**外观**（跟随系统 / 暗色 / 亮色、动画强度：完整 / 精简 / 关闭）、**网络**（本机地址选择、端口冲突检测）、**高级**（配置目录、重置、导出诊断包）。
- 「动画强度」三档是**性能开关**：精简档关闭流光与呼吸，关闭档只保留 120ms 过渡。

| 组件 | 规格 | 动效 |
|---|---|---|
| Button 主 | 高 34，圆角 `--r-md`，`--accent` 底，深色文字 | hover 亮度 +8%，按下 `scale(0.97)`，点击径向波纹 |
| Button 次 | 透明底 + `--line-strong` 描边 | hover 底色 `--bg-hover` |

| IconButton | 32×32 方形 | hover 底色 |

## 6. 性能预算（硬约束）

| 指标 | 目标 | 手段 |
|---|---|---|
| 首屏可交互 | < 400ms | 前端纯静态资源，无框架、无构建；Python 侧先开窗再初始化服务 |
| 常驻内存（前端） | < 60MB | 不用 React/Vue；DOM 节点数 < 1500；列表虚拟化（>200 行时） |
| 动画帧率 | 稳定 60fps | 只动 `transform` / `opacity`；`will-change` 仅用于正在动画的元素；禁止动 `width/height/top/left` |
| 主线程占用 | 空闲 < 2% | 状态轮询 1s 一次且页面隐藏时暂停；事件用委托 |
| 日志/列表渲染 | 增量追加 | 只 append 新节点，超过 500 条裁剪头部；不用 innerHTML 全量重写 |

**必须遵守**
1. 页面切换只做 `opacity + translateY`，不做 scale（避免重绘模糊）。
2. 列表行 hover 用 `transform` 而非 `padding`。
3. 呼吸/流光动画统一在**同一个** `requestAnimationurame` 循环里驱动（一个 raf 驱动所有元素，而不是每元素一个 CSS animation，减少合成层数量）。
4. `prefers-reduced-motion` 或「动画强度=关闭」时，所有动画降级为 0ms 并停止 raf 循环。

## 7. 交互反馈清单

| 场景 | 反馈 |
|---|---|
| 启动 DLNA | 按钮进入 loading（内嵌旋转弧），成功后状态胶囊变绿 + 轨道节点亮起 + toast |
| 停止 DLNA | 状态胶囊变灰，轨道流光停止，toast「已停止」 |
| 字幕服务加载模型 | 进度条不确定态 + 文案「正在加载 Qwen3-ASR-0.6B…」，就绪后徽标转绿并显示显存占用 |
| 同步进行中 | 进度条 + 当前文件 + 预估剩余时间；期间源/目标选择器禁用 |
| 删除媒体根 | 行先变 `--danger-soft` 闪一下，再从列表移除（180ms 高度收拢） |
| 复制 IP | 图标切换为对勾 1.2s |
| 错误 | 卡片左侧 3px `--danger` 竖条 + 行内错误文本，不用弹窗打断 |

## 8. 无障碍与细节

- 所有可点击元素有 `:focus-visible` 外发光（2px `--accent`）。
- 状态不只靠颜色：图标 + 文本 + 颜色三重编码（色盲友好）。
- 数值变化超过阈值时数字滚动而非瞬变。
- 窗口最小宽度 960，最小高度 640；侧边栏在 < 1080 宽时折叠为 56px 图标条。
